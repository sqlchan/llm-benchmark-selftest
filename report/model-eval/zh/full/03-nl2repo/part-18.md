## 104. `ydata-profiling`（测试数 2182）

**中文规格**

请创建一个名为 ydata-profiling 的 Python 项目，实现一个自动化数据探索与分析库。项目应包含以下功能：

1. 自动数据类型推断：自动识别 DataFrame 中每一列的数据类型（数值型、类别型、布尔型、时间型、文本型、文件、图像、路径、URL、时间序列等），并在报告中展示类型分布。

2. 单变量统计分析：为每一列生成描述性统计（例如均值、方差、分位数、唯一值、缺失值、极值、分布直方图等），并支持多种可视化。

3. 多变量相关性分析：自动计算多种相关性（例如 Pearson、Spearman、Phi_k、Cramér's V、Kendall 等），并生成相关矩阵与可视化。

4. 缺失值与异常检测：统计缺失值、零值、唯一值、常量、极值、异常分布等，并生成缺失值的可视化（柱状图、热力图、矩阵图等）。

5. 重复值检测：检测并统计重复行与近似重复行，并在报告中展示。

6. 数据质量警告：自动生成数据质量警告（例如高相关性、高基数、常量、唯一性、脏类别、偏度、均匀分布、非平稳性、季节性等），并在报告中高亮显示。

7. 样本采样与展示：支持多种样本采样方式（head、tail、随机、自定义），并在报告中展示样本数据。

8. 时间序列分析：针对时间序列数据自动分析自相关、季节性与趋势等特征，并生成相关可视化。

9. 文本与文件/图像分析：针对文本、文件、图像等特殊类型的数据开展专门分析（例如字符分布、EXIF、哈希等），并在报告中展示。

10. 交互关系与可视化：自动生成变量之间的交互关系（例如散点图矩阵、交互热力图等），并支持交互式可视化。

11. 报告导出与多格式支持：支持 HTML、JSON、Jupyter widgets 等多种报告导出方式，便于团队共享与自动化集成。

12. 多数据集对比：支持对两个数据集的结构与分布进行自动对比分析，并输出差异报告。

13. 灵活配置：支持 YAML/py 配置、命令行参数，以及 minimal/sensitive/exploratory 等多种模式，以便在不同场景中灵活使用。

14. 多后端支持：支持 pandas 与 pyspark 等多种数据处理后端，以适应大数据与分布式场景。

15. 集成与可扩展性：支持与 Jupyter Notebook、命令行界面、Python 脚本等多种环境集成，并通过自定义 handler 与 summarizer 提供良好的可扩展性。

16. 典型用法与示例：提供详细的 API 用法、命令行用法、Jupyter 用法以及典型数据集分析示例。

17. 自动化测试与质量保证：针对上述所有功能点设计自动化测试用例，覆盖主流程、异常边界、不同数据类型与不同后端，以确保功能的健壮性。

18. 核心文件要求：
项目必须包含完整的 `pyproject.toml` 文件，该文件不仅要把项目配置为可安装包（支持 pip install），还要声明完整的依赖列表（包括 `scipy>=1.4.1`、`pandas>1.1`、`matplotlib>=3.5`、`pytest` 等核心库）。pyproject.toml 应能验证所有功能模块是否正常工作；同时需要提供 `src/ydata_profiling/__init__.py` 作为统一 API 入口，从核心模块导入并导出核心函数、类等，并提供版本信息，使用户通过简单的 "from ydata_profiling import **" 语句即可访问全部主要功能。

**考点**：以「类型推断 → 单变量/多变量统计 → 质量警告」为主线的自动化 EDA 流水线，需统一打通 DataFrame 各类列类型的描述统计与相关性计算（Pearson/Spearman/Phi_k/Cramér's V/Kendall）、缺失与重复检测、时间序列与文本/文件/图像专用分析，并落到 HTML/JSON/widgets 多格式报告与 pandas/pyspark 双后端。
